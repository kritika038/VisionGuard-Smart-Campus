## Project Overview

VisionGuard Smart Campus is a production-ready attendance management platform built for schools, colleges, and training institutes. It provides centralized administration with a modern dashboard and scalable backend APIs.

The platform streamlines academic operations such as:

- Student record management  
- Teacher management  
- Subject and timetable management  
- Smart attendance monitoring  
- QR attendance workflow  
- Face recognition ready architecture  
- Real-time reports and analytics  
- Secure role-based login system
